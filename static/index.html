Send to iPhone

  1. Connect the iPhone to the same Wi-Fi network as this PC.
  2. Scan the code with the iPhone Camera and open the link in Safari.
  3. Safari warns about the connection, because this app signs its own certificate. Tap Show Details, then visit this website.
  4. Tap Save to Photos, then choose Save Images in the share sheet. Do this once for each batch.
